Disco at Discord

Privacy Policy

A simple summary of what this private bot stores and why.

1. Information the Bot Uses

The bot may use Discord server IDs, channel IDs, user IDs, display names, avatar URLs, voice channel state, and command input so it can respond to commands, route music controls, and show the dashboard.

2. Dashboard Login Data

When you sign in with Discord, the dashboard may store basic login records such as your Discord user ID, display name, avatar URL, login time, and whether you are a dashboard superuser. This is used for access control and administration.

3. Server Settings

The bot stores settings such as configured music channels, dashboard superuser IDs, soundboard entries, Spotify connection status, and other configuration needed to keep the bot working between restarts.

4. Logs

The bot keeps recent operational logs for troubleshooting. Logs may include command results, server names, IDs, playback errors, update results, and dashboard actions. Logs are intended for bot maintainers and dashboard superusers.

5. Soundboard Files

If you upload files for the soundboard, those files are stored on the bot server so they can be played later. Do not upload sensitive or private files. Maintainers or server administrators may remove soundboard files.

6. Spotify

If Spotify is connected from the dashboard, the bot stores a Spotify refresh token so it can load playlist or account-authorized Spotify metadata. The bot does not need your Spotify password.

7. Screen Activity

The custom screen Activity uses WebRTC between participants. The bot server provides signaling messages so users can connect, but it is not meant to record or permanently store shared screen video. Users choose what to share from their own device.

8. Third-Party Services

The bot interacts with Discord, YouTube, Spotify, and other services needed for playback or login. Those services have their own privacy policies and may receive requests from the bot or from your client.

9. Data Removal

To remove bot data from a server, remove the bot from the server or ask a bot maintainer to delete related settings, soundboard files, or dashboard records where practical.

10. Changes

This policy may be updated as the bot changes. Continued use of the bot means you accept the current version of this policy.
